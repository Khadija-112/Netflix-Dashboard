# 🎬 Netflix Dashboard

An interactive Netflix Dashboard built using **Tableau** to explore the distribution of Movies and TV Shows across countries, genres, ratings, and release years. The dashboard transforms raw Netflix data into meaningful visual insights, helping users understand content trends and the platform's growth over time.


## 📖 Overview

This project analyzes the Netflix Movies and TV Shows dataset from Kaggle using Tableau. It provides an interactive dashboard that enables users to explore Netflix's content library through dynamic filters and visualizations. The dashboard highlights trends in content production, genre popularity, ratings, and geographical distribution.


## ✨ Features

-Interactive filters for **Title** and **Content Type**

-Global distribution of Netflix content by country

-Movies vs TV Shows comparison

-Content ratings analysis

-Top 10 most popular genres

-Year-wise growth of Netflix content

## 📈 Key Insights

1. Movies account for nearly **70%** of Netflix's content library, while TV Shows make up around **30%**.
2. TV-MA and TV-14 are the most common content ratings.
3. Netflix experienced rapid content growth between **2016 and 2020**.
4. The United States contributes the largest share of Netflix content, followed by several other countries.
5. Interactive filters allow users to analyze individual titles and compare different content categories.


## 🎯 Business Value

This dashboard demonstrates how data visualization can uncover valuable insights from streaming platform data. It helps users understand content distribution, identify viewing trends, evaluate genre popularity, and explore Netflix's expansion across different countries and years. The project showcases practical skills in data storytelling, dashboard design, and business intelligence.
