# Netflix Dashboard

## Overview

The Netflix Dashboard is an interactive Tableau Public dashboard that analyzes Netflix's content library. It provides insights into movies and TV shows based on country, genre, ratings, release year, and content distribution through interactive visualizations.

## Features

- Interactive filters for Type and Title
- Content distribution by country
- Movies vs TV Shows comparison
- Ratings analysis
- Top 10 genres
- Year-wise content growth
- Title details including rating, duration, genre, and description

## Tools Used

- Tableau Public
- Microsoft Excel

## Dataset

**Netflix Movies and TV Shows Dataset**

Source: https://www.kaggle.com/datasets/shivamb/netflix-shows

## Outcome

The dashboard helps users explore Netflix's content library, identify content trends, compare movies and TV shows, analyze genre and rating distributions, and understand the platform's growth over time.
